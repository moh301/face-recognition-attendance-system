Face Recognition Attendance System

Overview
This project is a smart attendance system that uses face recognition and computer vision to automatically mark attendance.

Features
- Detects and recognizes faces
- Marks attendance automatically
- Uses real-time camera input
- Stores attendance data

Technologies Used
- Python
- OpenCV
- NumPy
- Face Recognition

How to Run
1. Install required libraries:
pip install opencv-python numpy face-recognition

2. Run the notebook or script

Dataset
The dataset contains sample face images used for recognition.
